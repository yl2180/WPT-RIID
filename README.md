# WPT-RIID 科研几何建模

本项目使用 Python 为 HFSS 生成三维几何，负责代码建模和几何交付。
后续计划依次读取同一坐标系下的头皮和皮层表面、根据已确认参数复现固定的 BISC 接收线圈 Rx、
在头皮附近生成传统发射线圈 Tx，再使用 RIID 优化 Tx 绕线路径。
所有几何尺寸和中心线坐标统一使用 **mm**。

## 完整圆环磁场算法验证

此脚本复用已有 `.venv` 中的 numpy 和 matplotlib，不安装或升级依赖。
从项目根目录执行：

```sh
.venv/bin/python scripts/magnetic_field_demo.py
```

### 模型与单位

完整单匝圆环在 XY 平面，圆心为原点，半径 `RADIUS_MM = 10.0 mm`，
电流 `CURRENT_A = 1.0 A`。从 +z 方向看向原点，正电流逆时针流动。
采用均匀自由空间、稳恒电流、理想细导线模型。
本例使用 **μ0 ≈ 4π×10⁻⁷ H/m** 的近似值，数值约 `1.2566370614e-6 H/m`；
不将它表述为现行 SI 中的精确定义值，参见 [NIST 的常数表](https://physics.nist.gov/cuu/pdf/all.pdf)。

几何输入、CSV 位置和绘图坐标用 **mm**；计算函数内部乘以 `1e-3` 转换成 **m**，
公式中的线段、距离、半径和轴向高度全部用 m，磁场结果为 **T**。
例如 10 mm 必须作为 0.01 m 代入。μ0 使用 SI 单位，直接把数值 10 当作米会导致磁场量级错误。

### 通用函数如何累加磁场

函数接口为：

```python
biot_savart(wire_points_mm, observation_points_mm, current_a, closed=False)
```

`wire_points_mm` 是按电流方向排列的 N×3 导线中心线坐标；
`observation_points_mm` 是想求磁场的位置，可为单个 `[x,y,z]` 或 M×3 数组。
返回值始终是 M×3，列为 `Bx, By, Bz`，单位 T。负电流反转磁场方向。

导线点表示“电流沿哪里走”；观察点表示“在哪里测算磁场”。二者是不同的点集。
对每一小段，取 `Δl = 终点 - 起点`，并以中点代表这段的位置。
令 `r = 观察点 - 线段中点`，用中点近似计算：

```text
ΔB = μ0 I / (4π) × (Δl × r) / |r|³
B  = 所有线段的 ΔB 按 x、y、z 三个分量分别相加
```

公式中的 `Δl × r` 是叉积，既包含大小也包含方向。不同线段的磁场可以加强或抵消，
所以不能只累加磁场大小。计算函数只接收折线，不假定它是圆环；
解析解由单独函数提供，只作对照，不参与数值磁场生成。
可参考 [Biot–Savart 定律](https://openstax.org/books/university-physics-volume-2/pages/12-1-the-biot-savart-law)。

闭合方式必须明确：

- `closed=False`：N 个点产生 N−1 段，不自动闭合。
- `closed=True`：本例给出 N 个独立圆环顶点，角度从 0° 开始且不重复 360° 点；
  函数将最后一个顶点连到第一个顶点，恰好得到 N 段。
- 因此本例 400 段对应 400 个独立坐标点。若 `closed=True` 又在末尾重复首点，函数会报错。

函数检查非法形状、非有限坐标/电流、零长度线段和观察点与输入折线接触的情况。
接触检查使用点到**整段有限直线段**的最短距离，包含端点和非中点位置；
距离不超过 `1e-12 m` 时按数值接触报错。这个阈值仅用于几何判定，
不是导线半径，也没有加到分母中。输入折线是对圆环的近似，检查对象是实际传入的线段。

每次只处理一条线段与所有观察点，临时数组随观察点数增长；
不建立“9261 个观察点 × 400 段 × 3”数组，不使用并行框架。

### 先验证，后生成场点集

验证点为圆心 `(0,0,0)` 和 `(0,0,R)`。完整圆环轴线理论值为：

```text
Bx = By = 0
Bz(z) = μ0 I R² / [2(R² + z²)^(3/2)]  （R 和 z 使用 m）
矢量相对误差 = norm(B数值 - B理论) / norm(B理论)
```

解析公式参见 [完整圆环轴线磁场推导](https://openstax.org/books/university-physics-volume-2/pages/12-4-magnetic-field-of-a-current-loop)。
本例理论值：圆心 `Bz = 6.2831853072e-5 T`，z=R 处 `Bz = 2.2214414691e-5 T`。

实际运行结果如下（表中误差为百分比；脚本同时打印完整数值和理论矢量）：

| 线段数 | 圆心数值 Bz / T | 圆心矢量相对误差 | z=R 数值 Bz / T | z=R 矢量相对误差 |
| --- | --- | --- | --- | --- |
| 50 | 6.3039060440e-5 | 0.329781% | 2.2221671640e-5 | 0.032668% |
| 100 | 6.2883561328e-5 | 0.082296% | 2.2216238551e-5 | 0.008210% |
| 200 | 6.2844774299e-5 | 0.020565% | 2.2214871256e-5 | 0.002055% |
| 400 | 6.2835083014e-5 | 0.005141% | 2.2214528870e-5 | 0.000514% |

全部检查 **PASS**：两点磁场指向 +z；横向分量范数除以理论场强小于 `1e-12`；
两点误差随段数增加严格减小；400 段时两点误差均小于 0.1%；
每种段数下改为 -1 A 后磁场逐分量反向、大小不变。
另外 8 项错误入口检查通过，涵盖非有限数值、零长度段、端点/内部点接触以及闭合最后一段。
验证失败返回非零退出码，不继续生成场点集。本次脚本退出码为 0。

### 本次验证的边界

本次覆盖轴线上两个点的解析对照、离散加密收敛、方向、电流反向、输入错误处理，
